# My Website

Pagina Next.js minimale, deployabile su Vercel.

```bash
npm install
npm run dev
```

Apri [http://localhost:3000](http://localhost:3000).

## Deploy su Vercel

1. Push del repo su GitHub
2. Importa il progetto su [vercel.com/new](https://vercel.com/new)
3. Vercel rileva Next.js da solo: conferma e deploy
